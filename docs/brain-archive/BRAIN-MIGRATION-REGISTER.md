## Column definitions

- **ID** — a stable identifier for this register row, assigned when the row is first added (never reused after removal).
- **Domain** — which area of Project Check the knowledge belongs to (Stage 1 / Stage 2 / Stage 3 / Evidence Intelligence / Planning Intelligence / Geometry / Governance / other).
- **Knowledge / Rule** — a short, specific description of the actual rule/knowledge (not a file name).
- **Source File** — the exact application-repository file the rule currently lives in.
- **Source Location** — line number(s), function name, or section heading within that file.
- **Governance Source** — the exact governing document/heading that authorises this rule (e.g. `MASTER-SPEC.md § "..."`, `EVIDENCE-INTELLIGENCE-SPEC.md § "..."`).
- **Current Governance Status** — the rule's existing classification (e.g. LOCKED/APPROVED, RECORDED FUTURE ARCHITECTURE, RETIRED, PROPOSED — NOT YET AUTHORISED) as recorded in the application repository's governance, unchanged by migration (Governance control 3).
- **Target Brain Location** — where in this repository's structure the migrated content will live.
- **Regression Test** — the test(s) that must exist and pass before removal from the application repository can be considered (Governance control 6).
- **Migration Status** — one of: `NOT STARTED`, `COPIED`, `VERIFIED`, `TESTED`, `INTEGRATED`, `VERIFIED AGAIN` (mirrors Governance control 7's method).
- **App Integration Status** — whether the application repository has been updated to consume the Brain copy through the controlled interface.
- **Removal Status** — whether the application-repository original has been removed; must stay blank/`NOT ELIGIBLE` until every condition in Governance control 6 is met and SPA has approved.
- **Notes** — anything else worth recording, including provenance detail that doesn't fit another column.
