## Lessons for Project Check
- This is the clearest example of the unheated Part L route (a statement plus 0.36/0.27 panels). Building Control acceptance isn't shown in the documents.
- Building Control forms were prepared but never filled in. Project Check should prompt users to keep the signed completion certificate.
