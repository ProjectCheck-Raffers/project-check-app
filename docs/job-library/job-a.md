## Lessons for Project Check
- Drainage and attenuation set by planning, plus mining-area ground, can add big civils costs after the building is designed. Flag these as "get professional support" early.
- Car park, drainage, EV charging and building each needed their own designer, order and, here, their own planning application.
- The client asked for a performance bond and defects insurance. These are commercial items, not regs.
